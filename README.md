# Akhil

Second-year B.Tech CSE (AI/ML) student at Woxsen University. Building AI/ML products and hardware projects. Currently interning at a T-Hub affiliated startup.

## Currently Working On

- Neurs — a pixel-art teaching web application. Pipeline: text prompt to Gemini image generation, deterministic grid conversion, layer-by-layer teaching, pixel editor.
- A student application for Woxsen University
- A film composition tool for pre-production shot planning, using AI to adjust lighting, test camera lenses and focus, and modify composition on a user-provided image

## Tech Stack

ML / DL: PyTorch, TensorFlow, Keras, Hugging Face, NumPy

LLMs / GenAI: Qwen, Gemini API, Ollama

Full-stack: React, TypeScript, Vite, FastAPI, Python

Infrastructure: Cloudflare Pages, Railway

## Projects

- [NumPy-Native Recurrent Neural Network](https://github.com/akhilreddyuppula/RNN-for-weather-prediction-using-numpy) — forward pass, BPTT, and gradient updates implemented manually, without Keras or PyTorch
- [Fine-Tuned Qwen for Domain-Specific Text Transfer](https://github.com/akhilreddyuppula/LLM-EnglishtoShakespeare-) — style-conditioned text generation via Hugging Face
- [Variational Autoencoder (MNIST)](https://github.com/akhilreddyuppula/Variational-AutoEncoder-MNIST-dataset) — PyTorch VAE trained on MNIST; encoder learns latent distributions (mu, sigma); BCE and KL divergence loss
- [Autoencoder (PyTorch)](https://github.com/akhilreddyuppula/Autoencoder-using-pytorch) — encoder compresses images into a latent vector; decoder reconstructs the image
- [Sequential Modeling with LSTM (PyTorch)](https://github.com/akhilreddyuppula/LSTM-stock-prediction) — LSTM applied to sequential financial data
- [Text-to-Image Generation with Stable Diffusion](https://github.com/akhilreddyuppula/StableDiffusion-text2image-)
